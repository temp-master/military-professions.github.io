# Атлас новых военных профессий

Современный одностраничный сайт на обычных HTML, CSS и JavaScript.

- адаптивная версия для телефона/планшета и компьютера;
- анимации появления, интерактивные карточки и мобильное меню;

## Задачи
1. Сделать картинку с 3 профессиями. 
Открываем презентацию под названием "Пример как надо оформить". На ней изображено 4 человека, которые представляют какую-то профессию (они имитируют какую-то профессиональную деятельность). Необходимо по данному примеру создать картинку, на которой будет изображено 3 человека, представляющие новые военные профессии. Открываем Word файл "Доклад". В нем нас интересует профессия "Инженер-мехатроник" и профессия "Инженер-оптомеханик". Открываем Word файл "Сведения о новых профессиях". В нем красным цветом выделены три те самые наименования военных специальностей, по которым необходимо сгенерировать картинку 3 людей, представляющих эти военные специальности. Специальность №1: Техническое обеспечение робототехнических систем и мехатронных устройств. Используя информацию о "Инженере-мехатронике" из Word документа "доклад" и собственные идеи, продумать, чем на картинке должен заниматься этот человек. То же самое продумать для специальностей "Программное обеспечение робототехнических систем и мехатронных устройств" и "Обслуживание и ремонт оптических и оптико-электронных приборов и систем". Для последней использовать информацию из документа Word "доклад" по "Инженер-оптомеханик". В презентации "Пример как надо оформить" в центре картинки изображен герб МО РФ. Вместо него в центр вставить герб ГРАУ (найти в интернете и попросить нейросет вставить ее в центр). В результате получится картинка с 3-мя представителями новых военных специальностей с гербом ГРАУ по центру. Расположить людей можно в виде треугольника (1 человек сверху по центру, двое по бокам, герб в центре).
2. Создать сайт.
На данном сайте на странице будет описываться информация об одной из трех этих военных специальностей. Соответственно должен быть сайт с 3 разными вкладками, где на каждой будет представлено наполнение по определенной специальности. Важно, чтобы вход был доступен только по QR-коду и нельзя было бы зайти по ссылке на страницу (если мы не хотим сливать конфиденциальные данные).
Предпочтения: милитари фон.
3. Сгенерировать 3 QR - кода. 
Сгенерировать 3 QR-кода, при сканировании которого пользователь будет переходить на ту самую вкладку сайта, где будет описана информация о новой военной специальности, QR-код которой он просканировал на буклетике.
4. Изменения: 
Поменять форму на российскую и добавить желтые курсантские погоны с буквой "К"
5. Изменения:
Изменения верстка Запихнуть страницу "Технологии в работе" в 1 страницу (сделать фотки чуть меньше, чтобы все уместилось). Сделать лист с Профессиями в 1 страницу, чтобы туда помещалось все 3 профессии (реализовать вариант Кинопоиска со стрелочкой вправо). При открытии ключевых задач, чтобы только одно окошко открывалось полностью, остальные не растягивались. При нажатии на картинку с человеком, чтобы показывало все 3 професии (получится, если поместить все 3 профессии на одну страницу.) Убрать в инженер-мехатроник и т.д. пробелы между буквами. В версии для телефона нужно, чтобы задачи раскрывались вниз, а не приходилось свапать наверх. Поменять в конце кнопку "в начало" на кнопку "Профессии будущего". Поменять "Технологии в работе" на "Специалисты в работе".

РТО - ракетно-техническое обеспечение.
АртТО - артиллерийско-техническое обеспечение.

## Локальный запуск

Можно просто открыть `index.html` в браузере. Для запуска через локальный сервер:

```bash
python3 -m http.server 8000
```

После этого сайт будет доступен по адресу `http://localhost:8000`.

## Замена фотографий

Чтобы заменить изображения без изменений в коде, сохраните новые файлы под теми же именами:

- `assets/images/robotics-lab.png`
- `assets/images/cyber-lab.png`
- `assets/images/optics-lab.png`
